D'après la figure de comparaison des modèles, on conclut qu'une approximation du **goodness of fit** est donnée par le dernier modèle ARIMA(2,0,2)(1,0,0)[12]. L'erreur moyenne du modèle est entre 40 et 45 dollars, donc ce modèle n'est pas mauvais puisque le prix de l'or par ounce est de l'ordre de 2000 dollars.  
Aussi, la prévision de ce modèle montre une tendance croissante. Ainsi, pour un acheteur, il s'avère mieux de le faire au début. Pour un vendeur, le faire vers la fin. Aussi, la stratégie la plus logique est "go long".
